# Style Heaven

Luxury silk e-commerce boutique for [Rony4505/style-heaven](https://github.com/Rony4505/style-heaven).

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

Admin: `admin@styleheaven.com` / `admin123`

## Railway

This repo includes a `Dockerfile` and `Caddyfile` so Railway can build the Vite app and serve it as a static site (React Router fallback included).

Connect the GitHub repo in Railway and set the deploy branch to `cursor/style-heaven-ecommerce-e958` until that work is on `main`.
